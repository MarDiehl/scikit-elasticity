scikit-elasticity#

A library for working with anisotropic elasticity in Python.

Homogenization#

Calculation of elastic constants from either elastic stiffness or compliance and a list of orientations. Inputs and outputs are plain NumPy arrays in Mandel notation. The orientation input must be a one-dimensional damask.Rotation. Hill-type estimates are available through C_Hill and S_Hill; select the scheme with method= (super_hill by default, also arithmetic_stiffness, arithmetic_compliance, geometric_log, or geometric_affine). The orientation-wise geometric mean is available separately as C_geo and S_geo.

>>> import skel
>>> import damask
>>> import numpy as np

>>> N = 1000
>>> C_Al = skel.Hooke.C('cubic',C_11=106.9e9,C_12=60.5e9,C_44=28.4e9)
>>> C_Al = skel.Mandel.to_6x6_stiffness(skel.Voigt.to_3x3x3x3_stiffness(C_Al))
>>> O = damask.Rotation.from_random(N)
>>> with np.printoptions(precision=2,suppress=True):
>>>    print(skel.homogenization.C_Reuss(O,C=C_Al)/1e9)
>>>    print(skel.homogenization.C_Voigt(O,C=C_Al)/1e9)
>>>    print(skel.homogenization.C_Hill(O,C=C_Al,method='arithmetic_stiffness')/1e9)
>>>    print(skel.homogenization.C_Hill(O,C=C_Al,method='arithmetic_compliance')/1e9)

Homogenization of elastic stiffness for ensembles of orientations.

The functions in this module take a set of orientations representing the texture together with either stiffness \(C\) or compliance \(S\) of a single crystal and calculate the effective stiffness or compliance in Mandel notation.

The orientations r must be a one-dimensional damask.Rotation.

The following schemes are available:

  • Voigt (isostrain) and Reuss (isostress) bounds

  • Hill averages, including arithmetic and bound-based geometric averages

  • superHill approximation

  • Orientation-wise geometric mean

  • Self-consistent scheme

Homogenized stiffness according to a Hill-type scheme.

Parameters:

  • r (damask.Rotation of shape (n,)) – One-dimensional array of orientations.

  • S|C (numpy.ndarray of shape (6,6)) – Stiffness or compliance matrix in Mandel notation.

  • method ({'arithmetic_stiffness', 'arithmetic_compliance',) – ‘geometric_log’, ‘geometric_affine’, ‘super_hill’}, optional Hill-type estimate to return. Defaults to super_hill.

  • tol (float, optional) – Relative convergence tolerance for super_hill. Defaults to 1e-10.

  • maxiter (int, optional) – Maximum number of iterations for super_hill. Defaults to 100.

Returns:

C_Hill – Homogenized stiffness in Mandel notation.

Return type:

numpy.ndarray of shape (6,6)

Notes

arithmetic_stiffness uses the average of C from Voigt and Reuss, arithmetic_compliance uses the inverse of the average of S, geometric_log and geometric_affine use the corresponding geometric mean of the Voigt and Reuss stiffness estimates, and super_hill uses the iterative superHill approximation. The orientation-wise geometric mean is available as C_geo().

Hooke#

Linear elasticity according to the generalized Hooke’s law.

This module assembles stiffness and compliance matrices in Voigt notation and provides directional and isotropic elastic properties.

Symmetry#

The form of the elastic tensor is determined by the point group of the crystal. Elasticity is a centrosymmetric fourth-rank tensor, so the relevant symmetry is the Laue class, i.e. the point group including inversion.

The crystal_system argument is a user-facing shorthand for the most general Laue-class form of a crystal system. The higher-symmetry class is obtained by omitting the optional constants or setting them to zero.

The relation between crystal systems, Laue classes, and the independent constants used here is:

triclinic

Laue class \(\bar{1}\); 21 independent constants.

monoclinic

Laue class \(2/m\); 13 independent constants. The twofold axis is parallel to \(x_2\) (Nye’s standard orientation).

orthorhombic

Laue class \(mmm\); 9 independent constants.

tetragonal

Laue classes \(4/m\) and \(4/mmm\). The general form has 7 constants with \(C_{16}=-C_{26}\). For \(4/mmm\), set \(C_{16}=C_{26}=0\), giving 6 constants.

trigonal

Laue classes \(\bar{3}\) and \(\bar{3}m\). The general form has 7 constants with \(C_{14}=-C_{24}=C_{56}\) and \(C_{15}=-C_{25}=-C_{46}\). For \(\bar{3}m\), set \(C_{15}=C_{25}=C_{46}=0\), giving 6 constants.

hexagonal

Laue classes \(6/m\) and \(6/mmm\); 5 independent constants with \(C_{66}=(C_{11}-C_{12})/2\).

cubic

Laue classes \(m\bar{3}\) and \(m\bar{3}m\); 3 independent constants.

isotropic

Not a crystal system; 2 independent constants with \(C_{44}=(C_{11}-C_{12})/2\).

All entries not listed as independent are either zero or related by the corresponding symmetry.

Universal anisotropy index.

Parameters:

Assemble a stiffness matrix.

Parameters:

  • crystal_system ({'isotropic', 'cubic', 'hexagonal', 'trigonal', 'tetragonal', 'orthorhombic', 'monoclinic', 'triclinic'}) – Crystal system. The assembled matrix uses the most general Laue-class form of this system; see the module documentation for the corresponding symmetry relations.

  • C_11 (float, optional) – Upper-triangle entries in Voigt notation. Only the independent entries for the selected crystal system need to be given. Dependent entries are inferred from the symmetry relations. If a dependent entry is supplied, it must be consistent with the inferred value.

  • C_12 (float, optional) – Upper-triangle entries in Voigt notation. Only the independent entries for the selected crystal system need to be given. Dependent entries are inferred from the symmetry relations. If a dependent entry is supplied, it must be consistent with the inferred value.

  • ... (float, optional) – Upper-triangle entries in Voigt notation. Only the independent entries for the selected crystal system need to be given. Dependent entries are inferred from the symmetry relations. If a dependent entry is supplied, it must be consistent with the inferred value.

  • C_66 (float, optional) – Upper-triangle entries in Voigt notation. Only the independent entries for the selected crystal system need to be given. Dependent entries are inferred from the symmetry relations. If a dependent entry is supplied, it must be consistent with the inferred value.

Returns:

C – Stiffness matrix in Voigt notation.

Return type:

numpy.ndarray of shape (6,6)

Raises:

ValueError – If the supplied entries violate the symmetry relations or the resulting matrix is not stable.

Notes

Only the upper triangle is given; the lower triangle is filled by symmetry. The following optional relations are used when entries are omitted:

  • tetragonal: \(C_{16}=-C_{26}\). If both are omitted, both are set to zero (\(4/mmm\)).

  • trigonal: \(C_{14}=-C_{24}=C_{56}\) and \(C_{15}=-C_{25}=-C_{46}\). At least one of \(C_{14},C_{24},C_{56}\) must be given. If \(C_{15},C_{25},C_{46}\) are all omitted, they are set to zero (\(\bar{3}m\)).

  • hexagonal: \(C_{66}=(C_{11}-C_{12})/2\).

  • isotropic: \(C_{44}=(C_{11}-C_{12})/2\).

The resulting matrix is checked with stable().

Examples

...                     C_44=16.5e9,C_33=61.7e9,C_13=21.5e9)

Determine whether a stiffness or compliance matrix is stable.

Parameters:

  • crystal_system ({'isotropic', 'cubic', 'hexagonal', 'trigonal', 'tetragonal', 'orthorhombic', 'monoclinic', 'triclinic'}) – Crystal system of the matrix. The stability criteria depend on the corresponding Laue class.

  • C (numpy.ndarray of shape (6,6), optional) – Stiffness matrix in Voigt notation.

  • S (numpy.ndarray of shape (6,6), optional) – Compliance matrix in Voigt notation.

Returns:

True if the matrix satisfies the Born stability criteria.

Return type:

bool

Raises:

  • TypeError – If neither or both of C and S are given.

  • ValueError – If crystal_system is not a valid crystal system.

Notes

The criteria are necessary and sufficient for elastic stability in the harmonic approximation and in the absence of external stress. They are taken from Mouhat and Coudert, who give them per Laue class.

For tetragonal and trigonal systems, the implementation uses the more general \(4/m\) and \(\bar{3}\) conditions. The higher-symmetry \(4/mmm\) and \(\bar{3}m\) cases are obtained by setting \(C_{16}=C_{26}=0\) and \(C_{15}=C_{25}=C_{46}=0\), respectively.

The matrix must have the symmetry of the selected crystal system. These criteria are not a general positive-definiteness test for an arbitrary 6x6 matrix.

If S is given, it is inverted to obtain C for the stability check.

References

F. Mouhat and F.-X. Coudert, Physical Review B 90:224104, 2014. https://doi.org/10.1103/PhysRevB.90.224104

Compressed notation of symmetric tensors using convention attributed to W. Voigt.

natural#

Compressed notation of symmetric tensors using a natural basis.

Notes

The following convention is used to store the unique elements of a 2nd order tensor t (3x3 matrix) as a vector t’ of length 6.

\[\vb{t}'_\text{natural} = (t'_1, t'_2, t'_3, t'_4, t'_5, t'_6)\]

The components are

\[\begin{split}t'_1 &= \frac{t_{xx}+t_{yy}+t_{zz}}{\sqrt{3}} \\ t'_2 &= \frac{2t_{zz}-t_{xx}-t_{yy}}{\sqrt{6}}\cos\theta + \frac{t_{xx}-t_{yy}}{\sqrt{2}}\sin\theta \\ t'_3 &= \frac{2t_{zz}-t_{xx}-t_{yy}}{\sqrt{6}}\sin\theta - \frac{t_{xx}-t_{yy}}{\sqrt{2}}\cos\theta \\ t'_4 &= \sqrt{2}t_{yz} \\ t'_5 &= \sqrt{2}t_{xz} \\ t'_6 &= \sqrt{2}t_{xy}\end{split}\]

The first component is the hydrostatic part, the next two components span the deviatoric plane, and the last three are the shear components. The optional parameter \(\theta\) rotates the deviatoric plane, i.e. it mixes \(t'_2\) and \(t'_3\).

Because the underlying basis is orthonormal, the Euclidean norm of the vector equals the Frobenius norm of the tensor.

T. Mánik, European Journal of Mechanics - A/Solids 90:104357, 2021 https://doi.org/10.1016/j.euromechsol.2021.104357

P. Lequeu, Comparison of crystallographic and continuum yield surfaces for textured polycrystals. PhD thesis, McGill University, Montreal, Canada, 1986 https://escholarship.mcgill.ca/concern/theses/nk322f063

P. Van Houtte, Texture, Stress, and Microstructure 8(1):313-350, 1988 https://doi.org/10.1155/TSM.8-9.313

Convert symmetric 4th order tensor in matrix notation to natural notation.

Parameters:

  • T (numpy.ndarray of shape (...,3,3,3,3)) – Symmetric 4th order tensor in matrix notation.

  • theta (float, optional) – Rotation angle (in radians) of the deviatoric plane. Defaults to 0.

Returns:

T_natural – Symmetric 4th order tensor in natural notation.

Return type:

numpy.ndarray of shape (…,6,6)

Notes

Due to the definition of the natural notation, this function can be used to convert compliance and stiffness tensors.
